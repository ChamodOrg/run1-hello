# Hello

## Problem Statement

Someone wants a minimal way to say hello: a single place where a visitor is greeted. There is no existing workaround; this is a deliberately tiny product.

## Solution

A simple web page that greets any visitor with a hello message, with no sign-in.

## Actors

- Visitor: anyone who opens the app; sees the greeting. No sign-in required.
